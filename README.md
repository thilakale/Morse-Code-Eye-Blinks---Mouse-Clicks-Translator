This project focuses on developing a Morse Code Translator using Python. The application is capable of converting English text to Morse code and Morse code back to English. It uses a dictionary to map characters to their Morse code equivalents and includes functions to perform the translation in both directions.
The user interacts with the program via the command line, selecting the translation mode and entering either plain text or Morse code. The translated output is then displayed accordingly.
This project introduces an innovative approach to hands-free communication by developing a Morse Code Translator controlled through eye blinks, leveraging computer vision techniques. The system allows users to input Morse code via short and long eye blinks, which are then translated into English text in real time.
This project offers great potential for assistive technologies, especially for individuals with limited mobility or speech impairments. It also demonstrates the practical application of computer vision in natural, intuitive user interfaces.
